# Sprite Pack 0.5.40.5

Este diretório é materializado durante o build a partir de `assets/characters/generated/fdc_character_pack_05405.zip`.

Para restaurar localmente antes de abrir o projeto na Godot:

```bash
python3 tools/restore_character_sprite_pack_05405.py
```

O pacote contém idle, caminhada, melee 1H/2H, armas de fogo 1H/2H, arco e coleta de animal em 8 direções.
